Tempel kode JSON

Satu kali tempel untuk banyak paket sekaligus. Bisa berupa daftar paket [ {…}, {…} ], satu paket {…}, atau {"packages":[…]}. Untuk menghapus, cukup daftar slug: ["bali-5d4n","dubai-6d5n"].

Sambung ke GitHub

Repo: . Token hanya disimpan di memori halaman ini dan hilang saat panel dikunci atau ditutup.

Cara buat token: GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token → Repository access: Only select repositories → givaholidays → Permissions: Contents = Read and write → masa berlaku pendek (mis. 30 hari).

Ekspor packages.json

Cadangan atau untuk diunggah manual ke repo.

Panduan singkat

  1. Buka tab Impor / Hapus JSON, tempel kode JSON paket, pilih mode, klik Periksa JSON.
  2. Cek hasilnya (merah = ditolak, kuning = diperbaiki otomatis), lalu Terapkan.
  3. Isi token di tab GitHub & Ekspor sekali, lalu klik Publish di bar bawah. Website ter-update dalam ±1 menit.
  4. Salah hapus? Klik Urungkan sebelum Publish. Paket bawaan yang dihapus bisa dipulihkan.

Format satu paket

{
 "slug": "bangkok-pattaya-5d4n",      // huruf kecil, angka, tanda minus
 "name": "Bangkok Pattaya 5D4N",
 "dest": "Thailand", "type": "Internasional",
 "days": 5, "nights": 4, "flags": ["th"],
 "color": "#0a3d91,#1f6fe0", "price": 6350000, "tag": "Promo",
 "image": "img/bangkok.jpg", "featured": false,
 "items": ["Hotel bintang 4", "Makan sesuai program"],
 "departures": ["2026-12-20*", "2027-01-10"],      // * = high season
 "departuresCompact": {"2027-02": "7 14 21*"},       // alternatif ringkas
 "daily": ["2027-03-01", "2027-03-31"],              // berangkat setiap hari
 "itinerary": [["Hari 1 - Jakarta", "Berkumpul di bandara…", "Hotel"]],
 "bonus": [], "included": [], "excluded": [], "costs": [], "terms": []
}

Keamanan

  • Kode akses di halaman ini hanya penghalang awal. Pengaman sebenarnya adalah token GitHub: tanpa token, tidak ada yang bisa mengubah website.
  • Gunakan token yang hanya untuk repo ini, masa berlaku pendek, dan jangan dibagikan.
  • Panel terkunci otomatis setelah 15 menit tanpa aktivitas, dan salah kode berkali-kali akan dikunci sementara.
  • Semua isi JSON dibersihkan (tanda < > dibuang, gambar/warna/tanggal diperiksa) sebelum tampil di website.
